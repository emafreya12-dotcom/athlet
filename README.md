# Athlet

Athlet is a Streamlit dashboard for athlete profiles, training, recovery, and nutrition tracking.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Publish a working public link

GitHub Pages cannot run this Python application. Deploy this repository with [Streamlit Community Cloud](https://share.streamlit.io/):

1. Create a new app from `emafreya12-dotcom/athlet`.
2. Select the `main` branch.
3. Set the main file to `app.py`.

The resulting `streamlit.app` URL is the public link to share.
